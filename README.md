
# Social Media Caption Generator

## Project Description
An AI-powered application that generates three creative social media captions and relevant hashtags from a short user description.

## Platforms Supported
- Instagram
- LinkedIn
- X (Twitter)

## Technologies Used
- Python
- Google Gemini API
- Gradio
- Google GenAI SDK

## Installation

Install the required libraries:

pip install -r requirements.txt

## API Key Setup

Set your GEMINI_API_KEY environment variable with your Google Gemini API key.

## Run Application

python app.py

## Features
- Generates three caption suggestions.
- Supports three social media platforms.
- Creates relevant hashtags.
- Provides a simple user interface.
